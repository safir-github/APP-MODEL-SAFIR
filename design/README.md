# Dossier des maquettes

Une maquette par concept d'application, en fichier HTML autonome (ouvrable seul dans un navigateur).

Format attendu :
- Tokens dans un bloc `<style>` : variables CSS dans `:root`, et `[data-theme="light"]` pour le thème clair.
- Écrans dans des `<section>` identifiés par `data-v` ou un identifiant.
- Données fictives dans un `<script>` séparé, faciles à repérer.
- Une version par fichier, nommée `maquette-<concept>-v1.html`, `-v2.html`, etc.

Ce dossier ne fait pas partie du modèle déployé. Voir docs/INTEGRATION.md.
